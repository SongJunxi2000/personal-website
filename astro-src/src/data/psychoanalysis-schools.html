经典精神分析

1890 年代至 1930 年代，维也纳。影响了：自我心理学、客体关系、人际间、自体心理学

一切的起点。人被潜意识中的驱力推动，症状是愿望与防御相互妥协的产物；治疗的任务是让潜意识的东西进入意识。

发展脉络

  1. 1895与布洛伊尔合著《癔症研究》，此后放弃催眠，改用自由联想
  2. 1900《梦的解析》，提出地形模型：意识、前意识、潜意识
  3. 1905《性学三论》，提出性心理发展阶段
  4. 1920《超越快乐原则》，引入死本能
  5. 1923《自我与本我》，提出结构模型：本我、自我、超我

代表人物

弗洛伊德Sigmund Freud
创始人，几乎所有核心概念的提出者
布洛伊尔Josef Breuer
早期合作者，"谈话疗法"源自他的个案安娜·O
亚伯拉罕、费伦齐Abraham, Ferenczi
第一代追随者；前者是克莱因的分析师，后者的关系取向影响了后来的人际与关系学派

核心观点

  • 潜意识决定了大部分心理生活
  • 驱力理论：力比多与攻击驱力寻求释放

    驱力是源自身体、持续产生的内部压力。积累时人感到紧张，释放时感到快感，这就是快乐原则。

    力比多是广义的性能量，指向快感、亲密与联结；攻击驱力指向破坏、敌意与支配。

    冲动不被现实和超我允许时会被压抑，但能量还在，会绕道从梦、口误、症状中出来，或升华为创作、竞技等活动。

    与生本能、死本能的关系：1920 年后弗洛伊德提出生本能（Eros）与死本能（Thanatos）。力比多是生本能的能量，攻击驱力是死本能转向外部的表现。两组说法基本对应，但"力比多与攻击"是临床层面的描述，"生死本能"带有思辨色彩。自我心理学只接受双驱力，多数不接受死本能；克莱因则把死本能作为理论的出发点。

  • 结构模型：本我、自我、超我之间的冲突
  • 性心理发展：口欲期、肛欲期、性器期、潜伏期、生殖期
  • 俄狄浦斯情结是神经症的核心

技术

  • 自由联想想到什么说什么，不加筛选，是基本规则
  • 释梦从显梦追溯隐意
  • 移情分析把来访者投向分析师的早年情感作为核心材料
  • 阻抗分析识别沉默、迟到、回避等对治疗的无意识抵抗
  • 诠释与修通说出潜意识的意义，并在反复工作中让领悟变成改变
  • 设置躺椅、每周多次；分析师保持中立、节制、匿名

自我心理学

"曾经的老大"老师的说法

1930 年代至 1970 年代，从维也纳、伦敦到美国。承自：经典精神分析。影响了：自体心理学

沿着弗洛伊德晚年的结构模型往前走，把目光从本我转到自我：自我不只是驱力的仆人，它有自己的适应功能。二战后随欧洲分析师移居美国，统治美国精神分析数十年。

发展脉络

  1. 1936安娜·弗洛伊德《自我与防御机制》，系统整理防御
  2. 1939哈特曼《自我心理学与适应问题》，提出"无冲突的自我领域"
  3. 1940 年代欧洲分析师为避战移居美国，自我心理学成为美国主流
  4. 1950埃里克森《童年与社会》，心理社会发展八阶段
  5. 1970 年代马勒发表分离-个体化研究；同时主流地位开始受到自体心理学和客体关系的挑战

代表人物

安娜·弗洛伊德Anna Freud
防御机制的系统化；儿童分析
哈特曼Heinz Hartmann
"自我心理学之父"，自我的自主性与适应
埃里克森Erik Erikson
把发展扩展到一生，强调同一性
马勒Margaret Mahler
分离-个体化理论
布伦纳Charles Brenner
现代冲突理论，妥协形成

核心观点

  • 自我的自主功能：知觉、记忆、思维等并非源于冲突
  • 防御机制：压抑、投射、反向形成、升华等，是理解人格的窗口
  • 适应：健康在于自我能灵活应对内外现实
  • 发展观：心理社会八阶段；分离-个体化

技术

  • 防御分析由表及里，先诠释"怎么防"，再触及"防什么"
  • 评估自我功能现实检验、冲动控制、焦虑耐受等，据此决定治疗方式
  • 治疗联盟与来访者能自我观察的部分合作，这是分析得以进行的基础
  • 冲突诠释指出愿望、焦虑、防御三者如何构成妥协
  • 保持经典设置仍然强调中立与节制

客体关系流派

"曾经最大的反对派，现在几乎做了老大"老师的说法

1920 年代起，英国。承自：经典精神分析。影响了：关系/主体间

人从出生起就在寻求关系，而不只是释放驱力。早年与照顾者的关系被内化成"内在客体"，此后人就带着这个内心世界去经历所有关系。关注点从俄狄浦斯期前移到母婴之间。

发展脉络

  1. 1926克莱因移居伦敦，用游戏技术分析幼儿
  2. 1941–45与安娜·弗洛伊德一派的"大论战"，英国学会分成克莱因派、安娜派和独立派
  3. 1946克莱因提出偏执-分裂位与投射性认同
  4. 1950 年代费尔贝恩主张"力比多寻求的是客体"；温尼科特提出过渡客体
  5. 1962比昂《从经验中学习》，容器与被容纳者
  6. 1975科恩伯格在美国把客体关系与自我心理学整合，用于边缘人格

代表人物

克莱因Melanie Klein
内在客体、两个心位、嫉羡、投射性认同
费尔贝恩Ronald Fairbairn
最彻底地用关系取代驱力
温尼科特Donald Winnicott
足够好的母亲、抱持、过渡客体、真假自体
比昂Wilfred Bion
涵容、α 功能；团体理论
科恩伯格Otto Kernberg
边缘人格组织；移情焦点治疗

核心观点

  • 内在客体：内化的关系模板支配着当下的体验
  • 偏执-分裂位与抑郁位：从"全好全坏"走向能容纳矛盾
  • 分裂与投射性认同：把无法承受的部分放进别人心里
  • 抱持性环境：足够好的照顾让真自体得以出现
  • 容器-被容纳者：母亲（治疗师）消化婴儿（来访者）无法消化的体验

技术

  • 游戏治疗把儿童的游戏当作自由联想来理解
  • 此时此地的移情诠释直接诠释来访者此刻如何体验治疗师
  • 使用反移情治疗师自己的感受是了解来访者内心世界的工具
  • 处理投射性认同接住被投射进来的东西，消化后再还给来访者
  • 抱持与涵容稳定的设置和不报复、不崩溃的在场本身就有治疗作用
  • 移情焦点治疗澄清、面质、诠释三步，整合分裂的自体与客体表象

人际间精神分析

"独行侠，有创造力"老师的说法

1930 年代起，美国。承自：经典精神分析。影响了：关系/主体间

研究的单位不是一个人的内心，而是人与人之间实际发生的事。长期被美国主流的自我心理学排除在外，自成一家，却最早把治疗师看成互动的参与者。

发展脉络

  1. 1920 年代沙利文在医院治疗精神分裂症患者，形成人际视角
  2. 1930 年代沙利文、霍妮、弗洛姆、汤普森等人相互影响，转向社会文化因素
  3. 1943威廉·阿兰森·怀特研究所在纽约成立，成为人际学派大本营
  4. 1953沙利文遗著《精神病学的人际理论》出版
  5. 1970 年代莱文森等人把焦点进一步推向治疗室里"正在发生什么"

代表人物

沙利文Harry Stack Sullivan
人际理论的创立者
弗洛姆Erich Fromm
社会性格；《逃避自由》
克拉拉·汤普森Clara Thompson
怀特研究所的组织者，连接费伦齐与沙利文
弗洛姆-赖希曼Frieda Fromm-Reichmann
精神病的心理治疗
莱文森Edgar Levenson
当代人际学派代表

核心观点

  • 人格即人际模式：人格是反复出现的人际情境的相对持久的模式
  • 焦虑来自人际：最初由照顾者的焦虑传递给婴儿
  • 安全操作：为回避焦虑而采取的策略，如选择性忽视
  • 自我系统："好我""坏我""非我"
  • 并列失真：用过去的关系模板扭曲地看眼前的人

技术

  • 参与性观察治疗师既在互动之中，又观察这场互动
  • 详细询问追问"到底发生了什么、谁说了什么"，填补被忽视的细节
  • 聚焦实际互动关心真实发生的事，而不只是幻想
  • 一致性确认和来访者核对彼此的理解，修正失真的感知
  • 更主动的姿态常采用面对面，治疗师更直接、更真实地回应

自体心理学

"精神分析的人本主义革命"老师的说法

1970 年代起，芝加哥。承自：经典精神分析、自我心理学。影响了：关系/主体间

科胡特本是自我心理学的核心人物，却在治疗自恋型来访者时发现经典的诠释不起作用。他提出：这些人的问题不是冲突，而是缺陷，他们需要的是被共情地回应。

发展脉络

  1. 1959论文《内省、共情与精神分析》，把共情定为精神分析的观察方法
  2. 1971《自体的分析》，提出自恋有自己的发展线
  3. 1977《自体的重建》，自体心理学成为独立的理论
  4. 1984遗著《精神分析治愈之道》，系统阐述疗效机制
  5. 1980 年代后后继者分化，其中一支发展为主体间理论

代表人物

科胡特Heinz Kohut
创始人
沃尔夫Ernest Wolf
科胡特的合作者，系统整理自体客体需要
奥恩斯坦夫妇Paul & Anna Ornstein
临床应用与教学
利希滕贝格Joseph Lichtenberg
动机系统理论

核心观点

  • 自恋的正常发展：自恋不必被克服，而是会成熟
  • 自体客体：被体验为自体一部分、起支撑作用的他人
  • 三种需要：镜映（被看见）、理想化（有人可依靠）、孪生（有人和我一样）
  • 恰到好处的挫折：不带创伤的小失败推动成长
  • 转变性内化：把自体客体的功能逐步变成自己的

技术

  • 共情性沉浸从来访者的内部视角去体验，也叫替代性内省
  • 先理解，后解释先让来访者感到被懂得，再谈这种感受从何而来
  • 允许自体客体移情展开镜映移情、理想化移情、孪生移情，不急于当作防御去面质
  • 修复共情失败治疗师的失误不可避免，承认并一起理解它，这正是"恰到好处的挫折"

关系/主体间精神分析

"最强新人"老师的说法

1980 年代起，纽约。承自：客体关系、人际间、自体心理学

把前面三条线汇到一起：心理不是一个人的事，而是在两个人之间形成的。治疗师不可能站在场外观察，治疗室里发生的一切由双方共同造就。

发展脉络

  1. 1983格林伯格与米切尔《精神分析理论中的客体关系》，区分驱力模型与关系模型
  2. 1984斯托罗洛与阿特伍德《主体性的结构》，从自体心理学走向主体间理论
  3. 1988米切尔《精神分析中的关系概念》；本杰明《爱的纽带》
  4. 1991期刊《精神分析对话》创刊，关系学派有了自己的阵地
  5. 2001国际关系精神分析与心理治疗协会成立

代表人物

关系学派的奠基者，提出"关系矩阵"
阿伦Lewis Aron

本杰明Jessica Benjamin
相互承认；"第三方"

主体间场域理论

核心观点

  • 二人心理学：从研究"一个人的内心"转向"两个人之间"
  • 共同建构：移情与反移情由双方一起造成
  • 活现：双方不知不觉地把旧的关系模式演了出来
  • 多重自体状态：健康是能在不同的"我"之间自由往来
  • 相互承认：把对方当作另一个主体，而不只是自己需要的客体

技术

  • 识别并修通活现发现"我们俩陷进了什么"，一起退后一步去理解
  • 审慎的自我暴露在对治疗有益时，治疗师说出自己的感受或参与
  • 运用治疗师的主体性不再追求匿名，承认自己的影响无法避免
  • 协商与破裂修复僵局和冲突是工作的材料，而不是要排除的障碍
  • 相互但不对称双方相互影响，但治疗师始终对这段关系负有专业责任
